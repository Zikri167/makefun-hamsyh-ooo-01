# Funniest One-Line Out-of-Office Reply

A single-line out-of-office reply for the make.fun bounty: the laptop is in airplane mode — and so, emotionally, is its owner. The program writes exactly one line of text (75 characters, no trailing newline) to `entry.txt` in the output directory.

## Run

```sh
python3 main.py
```

By default the entry is written to `/output/entry.txt`. Set `OUTPUT_DIR` (or `MAKEFUN_OUTPUT_DIR`) to write it elsewhere:

```sh
OUTPUT_DIR=./out python3 main.py
```
